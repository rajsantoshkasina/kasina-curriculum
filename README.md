# Kasina Curriculum Repository

Welcome to the central repository for all Pre-reads and Lecture Scripts. 

To keep our content organized and easy to navigate, we are using a strict, standardized folder structure across all batches. Please follow the guidelines below when adding or updating content.

## 📂 Directory Structure

Every batch follows this exact folder structure:

```text
kasina-curriculum/
├── README.md
├── templates/
│   ├── pre-read-template.md
│   └── lecture-script-template.md
│
├── <batch-id>/                   ← e.g., iitreict-dsai-2605
│   ├── module-01-<topic>/        ← e.g., module-01-programming-data-foundations
│   │   ├── lecture-01-<topic>/   ← e.g., lecture-01-intro-python
│   │   │   ├── pre-read.md
│   │   │   └── lecture-script.md
│   │   ├── lecture-02-<topic>/
│   │   │   ├── pre-read.md
│   │   │   └── lecture-script.md
│   │   └── ...
│   ├── module-02-<topic>/
│   └── ...
└── <batch-id-2>/
